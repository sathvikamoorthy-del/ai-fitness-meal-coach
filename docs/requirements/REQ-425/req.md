# User sees today's workout and meals as a checklist

Requirement REQ-425 · Feature FEAT-1388 · Decision DEC-460

## Purpose
As a user, I can see today's workout and meals as a checklist.

Helps the user follow the plan day by day (brief feature 23).

## Behaviour
The user sees today's workout and meals from their plans as a checklist.

## Acceptance criteria
- The user sees today's workout and meals from their plans as a list.
- The user can tick items off.
- The list shows only items for today.

## Order
Order: 22 of 24
Depends on: User gets an AI weekly workout plan; User gets an AI meal plan
