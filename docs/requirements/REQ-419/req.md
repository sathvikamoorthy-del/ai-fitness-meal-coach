# User can log weight

Requirement REQ-419 · Feature FEAT-1382 · Decision DEC-454

## Purpose
As a user, I can record my weight over time.

Weight is the main measure of progress (G3).

## Behaviour
The user records their weight with a date and sees past entries.

## Acceptance criteria
- The user can record a weight for a date.
- Past weight entries are listed by date.

## Order
Order: 16 of 24
Depends on: User can set profile and fitness goal
Goal served: G3
