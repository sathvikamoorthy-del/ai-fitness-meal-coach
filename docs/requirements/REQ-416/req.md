# User can browse foods with nutrition values

Requirement REQ-416 · Feature FEAT-1379 · Decision DEC-451

## Purpose
As a user, I can browse foods with calories, protein, carbs and fat.

Correct calorie totals depend on food values (G3).

## Behaviour
The user browses foods, each with calories, protein, carbs and fat.

## Acceptance criteria
- The user sees a list of foods.
- Each food shows calories, protein, carbs and fat.
- The user can find a food by name.
