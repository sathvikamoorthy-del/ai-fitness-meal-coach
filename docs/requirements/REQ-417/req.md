# User can log a meal

Requirement REQ-417 · Feature FEAT-1380 · Decision DEC-452

## Purpose
As a user, I can record my breakfast, lunch, dinner and snacks.

Fast logging is a core goal (G2).

## Behaviour
The user records foods eaten as breakfast, lunch, dinner or snacks for a day.

## Acceptance criteria
- The user can log foods under breakfast, lunch, dinner or snacks.
- The logged meal appears for that day.
- Logging a meal takes less than 30 seconds.

## Order
Order: 14 of 24
Depends on: User can browse foods with nutrition values
Goal served: G2
