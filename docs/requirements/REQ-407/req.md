# User can set dietary preferences and allergies

Requirement REQ-407 · Feature FEAT-1370 · Decision DEC-442

## Purpose
As a user, I can set vegetarian or non-vegetarian and list my allergies.

Meal plans must fit the user's diet and avoid allergens (G1).

## Behaviour
The user sets vegetarian or non-vegetarian and lists allergies. The values are saved with the profile.

## Acceptance criteria
- The user can choose vegetarian or non-vegetarian.
- The user can add and remove allergies.
- Saved preferences and allergies are shown again when the user returns.
