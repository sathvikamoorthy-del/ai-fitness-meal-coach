# User sees progress charts

Requirement REQ-422 · Feature FEAT-1385 · Decision DEC-457

## Purpose
As a user, I can see charts of my weight, calories and workouts.

Weekly progress must be visible and correct (G3).

## Behaviour
The user sees charts of weight, calories and workouts over time.

## Acceptance criteria
- The user sees a chart of weight over time.
- The user sees a chart of daily calories.
- The user sees a chart of workouts done.
- Every chart point matches the logged data.

## Order
Order: 19 of 24
Depends on: User sees workout history and personal records; User sees daily calories and macros against target; User can log weight
Goal served: G3
