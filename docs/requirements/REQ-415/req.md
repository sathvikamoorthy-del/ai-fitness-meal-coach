# User gets a grocery list from the meal plan

Requirement REQ-415 · Feature FEAT-1378 · Decision DEC-450

## Purpose
As a user, I can get a grocery list built from my meal plan.

Helps the user follow the plan (brief feature 15).

## Behaviour
The app builds a grocery list from the user's meal plan.

## Acceptance criteria
- The user can open a grocery list for their meal plan.
- The list contains the items of the meals in the plan.
- After a meal swap, the list reflects the new meal.
