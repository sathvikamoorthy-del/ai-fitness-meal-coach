# User can build a workout plan

Requirement REQ-410 · Feature FEAT-1373 · Decision DEC-445

## Purpose
As a user, I can build a workout plan with days, exercises, sets and reps.

Lets the user plan their own training (brief feature 6).

## Behaviour
The user builds a plan with days, and for each day exercises with sets and reps.

## Acceptance criteria
- The user can add days to a plan.
- The user can add exercises from the library to a day, with sets and reps.
- The saved plan is shown again with its days, exercises, sets and reps.

## Order
Order: 7 of 24
Depends on: User can browse and search exercises
Goal served: brief only
