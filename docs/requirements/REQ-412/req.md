# User sees workout history and personal records

Requirement REQ-412 · Feature FEAT-1375 · Decision DEC-447

## Purpose
As a user, I can see my past sessions and my best lifts.

Shows workout progress over time (G3).

## Behaviour
The user sees past sessions and their best lifts.

## Acceptance criteria
- The user sees past sessions, newest first.
- The user sees a best lift per exercise.
- A best lift is derived only from logged sessions.

## Order
Order: 9 of 24
Depends on: User can log a workout session
Goal served: G3
