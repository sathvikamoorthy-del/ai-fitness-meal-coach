# User gets an AI weekly report

Requirement REQ-423 · Feature FEAT-1386 · Decision DEC-458

## Purpose
As a user, I can read a short AI-written summary of my week.

Summarises progress for the user (brief feature 20).

## Behaviour
The AI writes a short summary of the user's week from their logged data.

## Acceptance criteria
- The user can read a short AI summary of a week.
- The summary is based only on the user's logged data for that week.

## Order
