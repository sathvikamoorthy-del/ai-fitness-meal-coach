# DB design
Target DB: Turso libSQL (SQLite 3 dialect)
Constraints:
- Naming: plural snake_case tables, snake_case columns.
- Ids: `id TEXT` UUID generated by the app; reference tables use `code TEXT` as PK.
- Timestamps: `created_at`, `updated_at` as ISO-8601 TEXT (UTC); dates as `YYYY-MM-DD` TEXT.
- Delete: hard delete; user-owned rows `ON DELETE CASCADE` from `users`. No soft delete, no audit table.
- Tenancy: none; one user per account; every user-owned row has `user_id`.
- Units: metric only (kg, cm, ml); other units converted in the UI.
- Normal form: 3NF; totals, history, best lifts, grocery lists, streaks and chart data are derived by queries, not stored. Deviations: profiles.daily_calorie_target (computed on save) and profiles.weight_kg (copied from latest weight log), both by product-owner decision.
- Seeds: exercises (~40) and foods (~60) from the project's own seed files; reference tables seeded with the codes in their descriptions.
- Foreign keys enforced (`PRAGMA foreign_keys = ON`).

Sources: docs/project/source/01-project-brief.md; docs/project/intent.md; docs/requirements/REQ-404 to REQ-427 (req.md, mock.md)
Tables: db_design_tables.csv (Status: New = proposed by Claude · Feedback = open feedback to apply or answer · Final = accepted)

Timestamp defaults are written in full as `(strftime('%Y-%m-%dT%H:%M:%fZ','now'))` (UTC, ISO-8601 with milliseconds).
